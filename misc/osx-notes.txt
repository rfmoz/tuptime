==========================
| macOS notes - Tuptime |
==========================


Tuptime is compatible with macOS. Python 3 must be installed (via Homebrew,
python.org, or Xcode Command Line Tools) as modern macOS does not include
Python by default.

macOS has no equivalent to systemd's ExecStop= or FreeBSD's rc.d stop().
launchd sends SIGTERM to daemons at shutdown and then SIGKILL after a
configurable timeout. The plist sets TimeoutStopInterval to 5 seconds;
tuptime -g completes in under 100ms, so graceful shutdown is reliable
in practice.

The provided wrapper script (tuptime-wrapper) runs as a persistent launchd
daemon. It registers startup, updates the DB every 5 minutes, and traps
SIGTERM to register a graceful shutdown.

Note: /usr/bin/ is read-only on macOS 10.15 (Catalina) and later due to
System Integrity Protection (SIP). Use /usr/local/bin/ instead.

To install, copy both files and make the wrapper executable:

    # git clone --depth=1 https://github.com/rfmoz/tuptime.git
    # cp tuptime/src/tuptime /usr/local/bin/tuptime
    # chmod +x /usr/local/bin/tuptime
    # cp tuptime/src/launchd/tuptime-wrapper /usr/local/bin/tuptime-wrapper
    # chmod +x /usr/local/bin/tuptime-wrapper
    # cp tuptime/src/launchd/localhost.tuptime.plist /Library/LaunchDaemons/

Create the database directory:

    # mkdir -p /var/lib/tuptime

Load it (macOS 12 Monterey and later):

    # launchctl bootstrap system /Library/LaunchDaemons/localhost.tuptime.plist

On older macOS:

    # launchctl load -w /Library/LaunchDaemons/localhost.tuptime.plist

Verify it's running:

    # launchctl list | grep tuptime

To uninstall (macOS 12 Monterey and later):

    # launchctl bootout system /Library/LaunchDaemons/localhost.tuptime.plist
    # rm /Library/LaunchDaemons/localhost.tuptime.plist
    # rm /usr/local/bin/tuptime-wrapper
    # rm /usr/local/bin/tuptime

On older macOS:

    # launchctl unload /Library/LaunchDaemons/localhost.tuptime.plist
    # rm /Library/LaunchDaemons/localhost.tuptime.plist
    # rm /usr/local/bin/tuptime-wrapper
    # rm /usr/local/bin/tuptime
