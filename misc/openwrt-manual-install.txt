====================================
| OpenWRT manual install - Tuptime |
====================================


Install dependencies:

On OpenWRT 25.12 and newer (apk):

    # apk update && apk add python3-light python3-sqlite3 python3-logging

On OpenWRT 24.10 and older (opkg):

    # opkg update && opkg install python3-light python3-sqlite3 python3-logging

Get the code and copy the executable file:

    # wget -O /usr/bin/tuptime https://raw.githubusercontent.com/rfmoz/tuptime/master/src/tuptime
    # chmod 755 /usr/bin/tuptime

OpenWRT mounts /tmp as tmpfs and /var is a symlink to it, so the default database path /var/lib/tuptime/tuptime.db would be lost on every reboot.
Redirect it to a persistent path:

    # mkdir -p /opt/tuptime
    # ln -s /opt/tuptime/ /var/lib/tuptime

The init file recreates this symlink on every boot.

Add the cron execution. Include the following line in '/etc/crontabs/root':

    */5 * * * * /usr/bin/python3 /usr/bin/tuptime -q

Copy the init file and set the right permissions:

    # wget -O /etc/init.d/tuptime https://raw.githubusercontent.com/rfmoz/tuptime/master/src/init.d/openwrt/tuptime
    # chmod 755 /etc/init.d/tuptime

Start and enable cron and tuptime:

    # /etc/init.d/cron enable
    # /etc/init.d/cron start
    # /etc/init.d/tuptime enable
    # /etc/init.d/tuptime start

Test it:

    # tuptime

That's all, enjoy it.

NOTE: Embedded devices usually have a low-precision RTC that tends to drift over time. Enable NTP if available.
